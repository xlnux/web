# X Linux documentation

**X Linux** is a minimal, Arch-based distribution built from the official Arch
repositories, with a script-driven text installer, its own branding and a
provisioning layer.

This site collects the documentation of every repository of the `xlnux`
organization in English and Spanish. Use the sidebar to browse by component, or
start with the topics below.

## What you will find

- **X Linux** — the distribution: ISO build, installer and VM testing.
- **X for WSL** — importable rootfs and WSL configuration.
- **WSL scripts** — the friendly WSL user setup.
- **Scripts and CLI** — the provisioning payload and the `x` command.
- **xpm** — the Rust package manager.
- **xpkg** — the Rust package builder.
- **x-repo** — the binary package repository and the package portal.
- **web** — this documentation portal.
